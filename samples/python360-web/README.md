# Python 360 — ローカル版

実務Python入門を終えた人向けの、全36章・360問のコード読解演習アプリです。
数値入力251問・単一選択109問、採点・解説・ヒント・長文資料・復習・進捗確認を収録しています。

## Windowsで起動する

1. ZIPを右クリックし、「すべて展開」でフォルダー全体を展開します。
2. 展開したフォルダーの **start.bat** をダブルクリックします。
3. ブラウザに **http://localhost:4173** が開きます。

Python 3.8以上、またはNode.js 18以上が必要です。起動ファイルがインストール済みのものを自動で選びます。Python・Node.jsの両方を入れる必要はありません。
教材と画面は組み立て済みなので、通常の利用に **pip install・npm install・ビルドは不要**です。
どちらもない場合は、利用するランタイムの現在サポートされている版をインストールしてから、もう一度起動してください。

起動中の黒いウィンドウは開いたままにします。終了はそのウィンドウで **Ctrl+C**、またはウィンドウを閉じます。
ブラウザが自動で開かない場合は、アドレス欄に **http://localhost:4173** と入力してください。

## コマンド1つで起動する

このフォルダーで、次のいずれか1つを実行します。

```sh
python server.py
```

```sh
node server.mjs
```

Node.jsがある場合は `npm start` でも起動できます。WindowsのPythonランチャーを使う場合は `py -3 server.py`、macOS・Linuxでは `python3 server.py` または `sh start.sh` が使えます。
macOSでは、実行を許可した `start.command` のダブルクリックでも起動できます。

## 進捗と、ホスト版からの引き継ぎ

- 回答・下書き・しおりは、利用しているブラウザのこのサイトの保存領域に記録されます。
- ホスト版での進捗は自動では移りません。ホスト版の「学習の記録」→「バックアップを保存」でJSONを保存し、ローカル版の同じ画面で「バックアップを読み込む」を選んでください。
- ローカル版では、毎回 **http://localhost:4173** を使ってください。`127.0.0.1`、別のポート、別のブラウザは別の保存先になります。
- ブラウザのデータを削除する前や別の端末へ移す際は、バックアップを保存してください。
- シークレットモードでは終了時に記録が消えることがあります。通常のウィンドウで利用してください。

## 接続と動作範囲

サーバーはこのPCの `127.0.0.1` だけで待ち受けます。LANやインターネットへの公開、ChatGPTへのログインは必要ありません。
問題・採点・解説・フォント・長文8ファイルはすべて同梱しています。
第29章以降の実ソース調査や、外部の参考文献を開く場合はインターネット接続が必要です。

同じアプリがすでに起動している場合は、そのアプリをブラウザで開きます。
別のアプリが4173番ポートを使っている場合はエラーを表示します。必要なら `python server.py --port 4174` または `node server.mjs --port 4174` で変更できます。この場合、進捗は別の保存先になるため、バックアップから引き継いでください。
自動でブラウザを開きたくない場合は `--no-browser` を付けます。

## ファイル

| ファイル | 内容 |
|---|---|
| start.bat | Windows用の起動ファイル |
| server.py / server.mjs | Python / Node.jsのローカルサーバー |
| start.sh / start.command | macOS・Linux用の起動ファイル |
| public/ | 動作するアプリ一式。問題はdata.json、画面はapp.js、スタイルはstyle.css |
| tests/ | 採点・ローカルサーバー・ブラウザの検証コード |
| VALIDATION.md | 実施した検証と確認範囲 |

同梱フォントNoto Sans JPのライセンスは `public/fonts/LICENSE` にあります。
自主学習向けのため、正解データもアプリに同梱しています。

## 開発用テスト

実行する場合にだけ `npm install` と `npx playwright install chromium` を行い、`npm test` を実行します。PythonサーバーとNode.jsサーバーを検証するため、このテストには両方のランタイムが必要です。
教材の通常利用ではこの操作は必要ありません。
