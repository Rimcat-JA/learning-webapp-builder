# Learning Webapp Builder — 完成版 1.0.0

教材設計から、問題・解説、学習アプリの実装、動作検証、localhost版の納品までをAIに進めてもらうためのスキルです。回答いただいた15項目を反映しています。分野と問題数は固定しません。

## 使い始める

1. ZIPを展開し、`learning-webapp-builder`フォルダーをAIが読める作業場所に置きます。
2. Codex CLI／IDEではその作業場所を開きます。ChatGPT Workではフォルダーを含むZIPと教材を添付し、ファイルを読み取れる状態で使います。
3. 次の指示を送ってください。

```text
learning-webapp-builder/SKILL.mdを読み、このスキルに従って学習用Webアプリを完成させてください。

分野：［学ぶ内容］
対象者と既習内容：［開始レベル］
到達目標：［できるようになりたいこと］
教材：［添付資料／既存アプリ／新規作成］
希望する量：［問題数や学習時間。提案してよい場合はその旨］

Windows優先のlocalhost版にしてください。
公開範囲は確認なしに広げないでください。
既に明確な条件は聞き直さず、実装の細部は判断して完成まで進めてください。
```

自動呼び出しを使う場合は、利用環境のスキル登録機能へ`learning-webapp-builder`フォルダーを登録します。`SKILL.md`が入口です。登録方法や保存先は環境ごとに異なります。このZIPの受け取りだけで自動登録は行われません。上記の直接読み込みによる指示は、登録機能がない環境でも使えます。

## 含まれるもの

| 場所 | 内容 |
|---|---|
| `learning-webapp-builder/SKILL.md` | AI向けの作業手順と完成基準 |
| `schemas/` | 教材・問題・進捗のJSON Schema |
| `scripts/course_tools.py` | 六形式の参照採点、教材と進捗の検証 |
| `scripts/check_migration.py` | 問題IDと履歴を守る移行計画のチェック |
| `examples/` | 六形式と未検証の分岐を含む8問の教材、二人分の進捗例 |
| `tests/` | 正常・異常・境界・履歴移行の自動テスト |
| `references/` | 要件、教材設計、画面、保存・同期、改修、検証、納品の詳細 |
| `RELEASE_REPORT.md` | このスキル自体の検証結果 |

`schemas/`以下などは`learning-webapp-builder/`内のパスです。サンプル8問は共通形式の使用例で、今後作る教材の問題数や難易度を指定するものではありません。

## 付属ツールを実行する

Python 3.10以降を推奨します。付属の採点・検証・移行ツールと通常テストに追加パッケージは不要です。学習者はPythonを操作しません。これらはアプリを作るAI・開発者のためのツールです。

Windowsでは展開先でターミナルを開き、次を実行します。

```powershell
cd learning-webapp-builder
py -3 scripts/course_tools.py validate examples/course.json --progress examples/progress.json --json
py -3 -m unittest discover -s tests -v
```

macOS／Linuxでは`py -3`を`python3`に置き換えます。ファイルはUTF-8です。出力表示が崩れる端末では`PYTHONIOENCODING=utf-8`を設定してください。

検証は未検証のサンプル2問に対して警告を出します。これは想定どおりの動作です。未検証を黙って除外するのではなく、アプリで見える状態にして収録する契約です。

## 採点と保存の既定

- 単一選択、複数選択、数値、選択式穴埋め、並べ替え、一対一の対応付けに対応します。
- コード・自由記述の入力は学習者に求めません。実行時AI採点も前提にしません。
- 複数選択は順不同の完全一致、その他の非数値形式も全体一致を標準とします。部分点を導入する場合は追加仕様とテストが必要です。
- 数値は半角の有限数値を受け付けます。許容誤差は絶対誤差と相対誤差の大きい方です。全角数字、単位、桁区切りは参照採点器へ渡す前にUIで案内します。
- 暫定正答のある未検証問題は暫定採点、ない問題は保留。確定成績には混ぜません。
- ブラウザ保存・ローカルDB・認証同期を組み合わせます。同期先がないときは未接続と表示し、ローカルの学習・保存・バックアップを使える設計にします。
- 問題の更新後も過去の履歴を再採点・上書きしません。

## 既存アプリを改修する依頼例

```text
このスキルを使い、添付の学習アプリを改修してください。
元の問題IDと学習者の進捗を維持し、変更前のバックアップを作ってください。
変更内容：［変更したい内容］
教材と進捗の共通形式への変換、移行計画のチェック、
画面・採点・保存復元の検証まで行い、localhost版を納品してください。
公開はしないでください。
```

## サンプル：Python 360（このスキルで作った学習アプリ）

このスキルの出力例として、全36章・360問のPythonコード読解演習アプリ **Python 360** を同梱しています。

- ソース一式: [`samples/python360-web/`](samples/python360-web/)
- ZIP版: [Releases](../../releases) の `python360-web.zip`

起動は `samples/python360-web/` で `python server.py`（または `node server.mjs`、Windowsは `start.bat`）を実行し、`http://localhost:4173` を開きます。追加パッケージやビルドは不要です。詳細は [`samples/python360-web/README.md`](samples/python360-web/README.md) を参照してください。

## 版管理

初版はGitへ記録し、配布用のGit bundleにも収録しています。教材を作る際は生成するアプリのリポジトリで個別に変更を管理してください。このスキルのサンプルデータを学習者の実データとして取り込む必要はありません。
