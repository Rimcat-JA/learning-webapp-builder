# PCとスマートフォンの画面契約

## 共通する移動

ホームから章または自由練習を選び、問題に入り、回答確定後に解説へ進む。解説から次の問題、再挑戦、章、関連資料へ移動できる。復習一覧と進捗から同じ問題IDへ戻れる。資料を閉じると入力中の回答とスクロール位置が戻る。

| 画面 | PC | スマートフォン |
|---|---|---|
| ホーム・章一覧 | 章ナビゲーションと学習状況を並べる | 今日の学習と章カードを一列で表示 |
| 問題 | 問題・資料を並べて読める余白 | 問題を主画面に、資料は全高シートまたは独立画面 |
| 回答 | 選択肢と確定操作を近接配置 | 縦に選べる候補、画面下の確定操作。キーボードで隠れない |
| 解説 | 回答との比較と関連概念を表示 | 結論と根拠、誤りの理由を順に表示 |
| 復習 | 絞り込みと問題一覧を同時表示 | 絞り込みシートと一覧。解除状態が分かる |
| 模擬試験 | 問題と解答状況ナビゲーション | 現在問を優先し、一覧は開閉式 |
| 進捗 | 章別と全体を比較 | 全体→章→問題へ段階的に表示 |

幅の目安はスマホ390px、PC1280px。境界は実際の内容が無理なく収まる位置で決める。タブレットや画面回転でも回答状態を失わない。UA文字列だけに依存しない。

## 操作と状態

- 単一選択はラジオ、複数選択はチェックボックス等の意味が伝わる要素にする。
- 数値入力は数値向けキーボードを補助し、負数や小数の必要性に合わせる。ブラウザ入力の制限だけを採点仕様にしない。
- 複数選択の上限・完全一致などのルールを回答前に示す。
- 並べ替えは上へ／下へボタン、対応付けは選択操作を用意し、ドラッグなしでも解ける。
- 未入力や形式エラーは該当箇所へフォーカスを移し、回答履歴を作らない。
- 採点結果の正誤は文字とアイコンでも表し、読み上げへ適切に通知する。
- リロード、戻る、資料表示、画面幅変更で入力中の回答を意図せず失わない。
- 回答連打で履歴が重複しない。再挑戦は新しいattempt IDを作る明示操作にする。
- ログアウト・学習者変更時は前の学習者の画面と未保存入力を持ち越さない。
- 同期中・未接続・失敗・保存済みを区別する。保存失敗の際に「保存しました」と表示しない。

## 模擬試験

開始前に問題数、時間、採点規則、未検証の有無を表示する。開始・期限・選択問題IDとrevision・解答・提出状態を保存する。残り時間は期限との差分から算出する。復帰時に期限を過ぎていれば二重処理せず終了する。

提出までは正解・解説・即時正誤を伏せる。途中提出は未回答数を知らせる。確定後は全体結果、未回答、誤答、暫定・保留を分ける。終了した模試を再度提出しても履歴を複製しない。

PCとスマホで同じ必須タスクを一巡し、それぞれのスクリーンショットを残す。スクリーンショットだけで操作検証済みとはしない。
